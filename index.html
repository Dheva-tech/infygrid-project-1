Architecture, Local XAMPP Setup & Viva Guide

Step-by-step instructions for running this system with PHP & MySQL in XAMPP, WAMP, or Laragon.

How to Run in XAMPP / WAMP

  1. Install XAMPP: Download and install XAMPP with PHP 8.0+ and MySQL from apachefriends.org.
  2. Start Services: Open the XAMPP Control Panel and click Start next to both Apache and MySQL.
  3. Create MySQL Database: Open your browser and navigate to http://localhost/phpmyadmin/. Create a new database named medicare_management with collation utf8mb4_unicode_ci.
  4. Import SQL File: Click on the medicare_management database in phpMyAdmin, switch to the Import tab, select database/medicare_management.sql from this repository, and click Go.
  5. Deploy Code: Copy the entire project folder into your XAMPP webroot: C:\xampp\htdocs\medicare_management\.
  6. Configure Database: Check php-backend/config/database.php if your MySQL port or password differs from the default (host: 127.0.0.1, user: root, password: empty).
  7. Access Application: Visit http://localhost/medicare_management/ in any browser. The system will automatically detect the active PHP PDO backend!

Viva & Interview Defense Guide

PDO (PHP Data Objects) provides a consistent database abstraction layer supporting prepared statements with named parameters (:id), robust exception handling (PDOException), and driver independence. Prepared statements completely eliminate SQL Injection vulnerabilities.

In php-backend/api/orders.php, order creation is wrapped in an atomic database transaction (beginTransaction(), commit(), rollBack()). Each product row is checked with FOR UPDATE locking to verify: 1) product is not expired (rejected if expiry_date < CURDATE()), and 2) stock quantity is sufficient. Stock is decremented in the same transaction.

The schema is normalized to 3rd Normal Form (3NF). Entities (categories, suppliers, products, customers, orders, order_items) are strictly isolated with foreign key constraints, eliminating transitive dependencies and update anomalies.

Two-tier validation: Frontend validation in js/validation.js provides immediate user feedback before network requests. Backend validation in PHP enforces strict checks on data types, positive numbers, valid foreign keys, duplicate unique keys, and expiry dates with HTTP 422/409 status codes.
